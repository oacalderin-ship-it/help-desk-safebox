How privacy works

Processing occurs in your browser. This version has no AI API or ConnectWise API integration, analytics, or telemetry. Ticket content, screenshots, extracted text, notes, findings, and prompts are not intentionally persisted. Screenshot text is read locally with a bundled OCR engine; no image is uploaded. Suggested context uses simple text rules, not AI image understanding. Only your selected prompt mode is remembered locally.

Automatic detection is imperfect and user review is required. Company policy always takes precedence over this tool. Clearing removes content from the interface and app references; it does not securely erase browser memory or your system clipboard. Browser extensions, clipboard history, and device software are outside this app’s control.

Hosting loads the app’s local files normally. After loading, scanning and prompt generation make no network requests. For offline use, open the downloaded index.html.
